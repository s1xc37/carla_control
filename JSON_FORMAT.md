# Формат JSON: что происходит у перехода

Симуляция (CARLA, Town05, наш переход) отдаёт состояние участка сообщениями.
Одно сообщение — один JSON-объект, UTF-8, текстовый кадр WebSocket.

## Как подключиться

`ws_sender.py` поднимает WebSocket-сервер `ws://<ip машины с симуляцией>:8765` и рассылает сообщение
всем подключённым раз в 0.5 с времени симуляции. Отправлять ему ничего не нужно — только слушать.

```python
# pip install websockets
import asyncio, json
from websockets.asyncio.client import connect

async def main():
    async with connect("ws://<ip>:8765") as ws:
        async for raw in ws:
            msg = json.loads(raw)
            print(msg["phase"], len(msg["vehicles"]), msg["pedestrians"])

asyncio.run(main())
```

```js
// браузер / Node
const ws = new WebSocket("ws://<ip>:8765");
ws.onmessage = (e) => { const msg = JSON.parse(e.data); console.log(msg.phase, msg.pedestrians); };
```

Симуляция обычно идёт быстрее реального времени, поэтому по часам сообщения приходят чаще, чем раз
в 0.5 с. Время внутри сообщения — поле `t`.

## Пример

```json
{
  "t": 123.45,
  "frame": 2469,
  "phase": "PED",
  "vehicles": [
    {"id": 231, "type": "car",     "lane": 3, "direction": "in",  "speed_kmh": 0.0},
    {"id": 245, "type": "bus",     "lane": 1, "direction": "out", "speed_kmh": 32.5},
    {"id": 250, "type": "special", "lane": 4, "direction": "in",  "speed_kmh": 41.0}
  ],
  "pedestrians": {
    "waiting": {"W": 2, "E": 1},
    "crossing": 0
  }
}
```

## Поля

| поле | тип | смысл |
|---|---|---|
| `t` | float, с | время симуляции CARLA (с загрузки мира); растёт на 0.5 между сообщениями |
| `frame` | int | номер кадра CARLA |
| `phase` | `"MAIN"` / `"SIDE"` / `"PED"` | фаза светофоров: едет главная дорога / едет наша дорога / всем машинам красный, идут пешеходы. Считается по цветам: жёлтый — ещё `MAIN`/`SIDE`, очистка перехода (всем красный, по 3 с до и после пешеходов) — уже `PED` |
| `vehicles` | список | машины на нашей дороге (см. ниже); пустой список, если машин нет |
| `vehicles[].id` | int | id машины; не меняется, пока машина в сцене — по нему можно следить за ней между сообщениями |
| `vehicles[].type` | `"car"` / `"van"` / `"truck"` / `"bus"` / `"special"` | тип техники (см. ниже) |
| `vehicles[].lane` | int, 1–4 | номер полосы (см. ниже) |
| `vehicles[].direction` | `"in"` / `"out"` | едет к переходу / от перехода |
| `vehicles[].speed_kmh` | float, 1 знак после запятой | скорость, км/ч |
| `pedestrians.waiting` | `{"W": int, "E": int}` | сколько людей в зоне ожидания с каждой стороны перехода |
| `pedestrians.crossing` | int | сколько людей сейчас на самой зебре |

## Какие машины попадают в `vehicles`

Машины на **4 полосах нашей дороги** — той, которую пересекает зебра, — в пределах **50 м** от центра
зебры, в обе стороны, включая тех, кто сейчас на самой зебре. Машины на главной дороге не попадают.

## Полосы

Полосы считаются **с запада на восток** поперёк дороги (W и E — те же стороны, что у пешеходов):

```
          от перехода      к переходу
           ↑       ↑       ↓       ↓
        |  1   |   2   |   3   |   4   |     ← наша дорога (2 + 2 полосы)
   W ●══╪══════╪═══════╪═══════╪═══════╪══● E ← зебра; ● — зоны ожидания пешеходов
                  (дальше — перекрёсток с главной)
```

- `1`, `2` — едут **от** перехода (`"direction": "out"`);
- `3`, `4` — едут **к** переходу (`"direction": "in"`), это они стоят у стоп-линии на красный.

## Типы техники

Берутся из атрибутов модели CARLA (`base_type`, `special_type`):

| `type` | что это | примеры моделей CARLA |
|---|---|---|
| `car` | легковая, в том числе такси и электромобили | audi.a2, tesla.model3, ford.crown (такси) |
| `van` | фургон, микроавтобус | mercedes.sprinter, volkswagen.t2 |
| `truck` | грузовик | carlamotors.carlacola, tesla.cybertruck |
| `bus` | автобус | mitsubishi.fusorosa |
| `special` | спецтехника: полиция, скорая, пожарная (`special_type = emergency`) | dodge.charger_police, ford.ambulance, carlamotors.firetruck |

Если у модели пустой `base_type` (mini.cooper_s, bmw.grandtourer), она считается `car`.

## Пешеходы

- **Зона ожидания** — прямоугольник 3×3 м вокруг точки ожидания у бордюра:
  W — (24.45, −178.75), E — (42.91, −176.16), координаты CARLA.
  Считаются все люди, которые сейчас внутри зоны, по положению, как посчитала бы камера.
- **`crossing`** — люди внутри контура зебры (контур из `get_crosswalks()`).

## Чего в формате нет

Координат машин, id пешеходов и флага «группа». При текущем лимите 3 пешехода на сторону группа
не набирается.
