# Умный пешеходный переход — симуляция в CARLA

Симуляция участка для кейса «умный регулируемый переход»: T-перекрёсток в Town05, зебра через
дорогу 2+2. В мире ездят машины, ходят пешеходы, светофоры переключает наш скрипт.
Состояние участка (машины, пешеходы, фаза) уходит другу по WebSocket в JSON.

```
 CARLA-сервер ◄── run_scene.py (+ pedestrians.py)   крутит мир: светофоры, машины, пешеходы
      ▲
      └──────── ws_sender.py ──► ws://<ip>:8765 ──► друг   только читает мир и рассылает JSON
```

## Файлы

| файл | что делает |
|---|---|
| `run_scene.py` | **главная сцена.** Синхронный режим, фазы светофоров, поток машин, пешеходы, статистика в консоль |
| `pedestrians.py` | пешеходы на переходе. Подключается к `run_scene.py` сам. Отдельный запуск — только рисует геометрию |
| `ws_sender.py` | отдельный процесс: читает мир и рассылает JSON по WebSocket |
| `JSON_FORMAT.md` | формат сообщений — это отправлять другу |
| `find_crossings.py` | поиск переходов на карте, загрузка карты (`--map Town05`) |
| `main.py` | разведчик: рисует светофоры, переходы и точки спавна у центра |
| `CLAUDE.md` | контекст проекта и все найденные грабли — читать, если что-то странное |

## Подготовка (один раз)

- CARLA 0.9.16 лежит в `~/simulator`, Python-окружение — `~/simulator/.venv` (в нём `carla==0.9.16`).
- Для отправки нужна `websockets`. В этом venv нет pip, ставится через uv:
  ```bash
  uv pip install --python ~/simulator/.venv/bin/python websockets
  ```

## Запуск

1. **Сервер CARLA** (отдельный терминал):
   ```bash
   ~/simulator/CarlaUE4.sh -quality-level=Low
   ```
2. **Карта Town05**, если загружена другая (сбрасывает мир):
   ```bash
   cd ~/carla_control && ~/simulator/.venv/bin/python find_crossings.py --map Town05
   ```
3. **Сцена** (второй терминал):
   ```bash
   cd ~/carla_control && ~/simulator/.venv/bin/python run_scene.py
   ```
   Камера сама встанет над переходом. Дальше в окне CARLA камеру двигаешь мышью и WASD.
4. **Отправка другу** (третий терминал, после сцены):
   ```bash
   cd ~/carla_control && ~/simulator/.venv/bin/python ws_sender.py
   ```
   Друг подключается к `ws://<твой ip>:8765`. Свой ip: `hostname -I`.
   Порт 8765 должен быть открыт в фаерволе, если друг в другой сети.
5. **Остановка:** `Ctrl+C` **один раз** в терминале сцены. Скрипт сам уберёт машины и пешеходов
   и отпустит мир. `ws_sender.py` останавливается так же, мир он не трогает.

Проверить геометрию перехода без запуска сцены: `python pedestrians.py`. Скрипт на 60 с рисует
контур зебры (белый), торцы (красные), зоны ожидания W (зелёная) и E (синяя), точки появления людей.

## Что пишет сцена раз в секунду

```
[MAIN   12s] наш=Red  в зоне= 14  ждут у нас= 3  +57 -47 (не влезло 0)
   пеш: ждут W= 1 (макс  13с) E= 2 (макс   8с)  ср.ожид   9с (у перешедших 17с) | идут 2 переходят 0 уходят 1 | перешло 35 ...
```

- **Первая строка — машины:** фаза и секунда внутри неё, цвет нашего светофора, машин в зоне,
  сколько стоит у нашей стоп-линии, сколько появилось и удалено.
- **Вторая строка — пешеходы:** сколько ждёт с каждой стороны и дольше всех, среднее ожидание,
  сколько идёт, переходит и уходит, сколько всего перешло.
- **Строки с `!`** — проблемы: `застрял` (пешеход убран), `долгий переход`. Если их много, что-то не так.

## Как управлять — параметры

Всё настраивается константами в начале файлов. Поменял — перезапустил скрипт.

### `run_scene.py` — светофоры и машины

| параметр | сейчас | что меняет |
|---|---|---|
| `PHASES` | MAIN 20 / SIDE 15 / PED 20 с | цикл светофора: едет главная / едет наша дорога / всем машинам красный, идут пешеходы. **PED не делай меньше ~18 с**: пешеходы не успеют начать переход (переход 17–18 м) |
| `VEH_PER_HOUR` | 1200 | сколько машин в час появляется на всех подъездах |
| `MAX_VEHICLES` | 60 | потолок машин одновременно (бережём сервер) |
| `SOURCE_RING`, `SINK_RADIUS` | 40–150 м, 170 м | где появляются и где удаляются машины |
| `SEED` | 42 | зерно случайности. Тот же SEED — тот же поток |

Сейчас светофор работает **по таймеру**, на число машин и пешеходов не смотрит.

### `pedestrians.py` — пешеходы

| параметр | сейчас | что меняет |
|---|---|---|
| `PED_PER_HOUR` | 360 | сколько раз в час появляется пешеход (на обе стороны) |
| `MAX_PER_SIDE` | 3 | больше стольких живых людей с одной стороны не появится. **Сильно не поднимай**: в толпе люди сталкиваются и физика выбрасывает их на дорогу |
| `SPEED` | 1.2–1.6 м/с | скорость ходьбы |
| `CROSS_MARGIN` | 2 с | запас: человек начинает переход, только если до конца PED осталось не меньше путь/скорость + запас |
| `GROUP_PROB`, `GROUP_SIZE` | 0, 5–10 | группы. Выключены: 5–10 человек не влезают в лимит 3 на сторону |
| `DRAW_DEBUG` | `True` | debug-отрисовка зон. **Выключи, когда пишешь кадры для YOLO**, иначе отрисовка попадёт в кадр |

Остальные параметры — тонкая настройка ходьбы (обход соседей, бордюр, «застрял»). Их лучше не трогать.

### `ws_sender.py` — отправка

| параметр | сейчас | что меняет |
|---|---|---|
| `HOST`, `PORT` | `0.0.0.0`, 8765 | где слушает WebSocket. `0.0.0.0` — доступен из сети |
| `SEND_PERIOD` | 0.5 с | как часто слать, в секундах **симуляции**. Симуляция идёт быстрее реального времени, поэтому по часам сообщений больше |
| `ROAD_LENGTH` | 50 м | докуда по нашей дороге считаем машины |
| `ZONE_HALF` | 1.5 м | зона ожидания пешеходов — квадрат 3×3 м у бордюра |

## Если что-то сломалось

- **Мир «замёрз»** — скрипт убили жёстко или нажали Ctrl+C дважды, мир остался в синхронном режиме.
  Вернуть и убрать остатки:
  ```bash
  ~/simulator/.venv/bin/python -c "
  import carla; c = carla.Client('localhost', 2000); c.set_timeout(10); w = c.get_world()
  s = w.get_settings(); s.synchronous_mode = False; s.fixed_delta_seconds = None; w.apply_settings(s)
  left = list(w.get_actors().filter('walker.*')) + list(w.get_actors().filter('vehicle.*'))
  c.apply_batch_sync([carla.command.DestroyActor(a.id) for a in left]); w.freeze_all_traffic_lights(False)
  print('ok, убрано', len(left))"
  ```
- **Пересвет или глюк рендера** — перезапусти сервер с `-quality-level=Low`.
- **`ws_sender.py` пишет «Нет тиков мира»** — сервер CARLA не запущен или завис.
- **id светофоров поменялись** после перезапуска — это нормально, скрипты ищут всё по позиции.
- Остальные грабли (почему пешеходы ручные, бордюр, коллизии) — в `CLAUDE.md`.
